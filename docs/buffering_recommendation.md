# Рекомендации по буферизации quality_gate.passed

Для SynapticTrainingHandler и пакетной обработки `strengthen_connections_batch` в ArtifactKB.

## Результаты бенчмарка

- **Batch (50 событий):** существенно быстрее 50 одиночных `strengthen_connection` (примерно 2x и более)
- **Оптимальный размер batch:** ≥10–20 событий даёт выигрыш; 50 — рекомендуемый максимум (соответствует оптимизации в artifact_kb при ≤50 updates)

## Параметры буферизации

| Стратегия | Нагрузка | Когда использовать |
|-----------|----------|-------------------|
| **50 событий** | Высокая | Много quality_gate.passed; flush при count >= 50 |
| **100 мс** | Низкая | Редкие события; flush при time_since_first >= 100ms |
| **Гибрид** | Смешанная | flush при `count >= 50` ИЛИ `time_since_first >= 100ms` |

Рекомендуется **гибридный** подход для production.
